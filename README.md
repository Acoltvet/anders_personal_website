# Anders Coltvet Portfolio

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript. No build step or package installation is required.

## Preview locally

Open `index.html` in a browser, or serve this directory with any static file server. The downloadable resume is stored at `assets/anders-coltvet-resume-2026.pdf`.

## Publish with GitHub Pages

The site is ready to publish from the repository root on the `main` branch. In the repository’s Pages settings, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
